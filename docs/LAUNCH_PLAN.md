# Launch plan

The goal is not to ask for stars. The goal is to make AgentMemora useful enough that developers save it, try it, and contribute.

## Positioning

**AgentMemora is open-source DevTools for AI agent memory — inspect writes, recalls, conflicts, timelines, latency, and provenance.**

Do not position it as another vector database or generic tracing platform.

## Release gate

- [x] Runnable local dashboard
- [x] Mem0 adapter + credential-free demo
- [x] LangGraph/LangMem adapter
- [x] Privacy-safe defaults tested
- [x] Provider-neutral events and latency dashboard
- [x] Python 3.10–3.13 CI
- [ ] Rename GitHub repository from EngramScope to AgentMemora
- [ ] Publish `v0.1.0-alpha`
- [ ] Set repository description/topics/social preview

## Launch sequence

1. GitHub `v0.1.0-alpha` release.
2. X thread with native demo media.
3. LinkedIn technical post with the problem and short demo.
4. Show HN after the public install path is verified.
5. Relevant Reddit posts asking for technical feedback.
6. Medium article 1–2 days later: **Your AI Agent Remembers — But Can You Debug Its Memory?**
7. Relevant curated-list PRs only after integrations are real and documented.

## Metrics

Track stars/day, unique cloners, package downloads, non-maintainer issues, external PRs, adapter requests, and repeat contributors. Optimize for real usage and contributors, not a one-day star spike.
